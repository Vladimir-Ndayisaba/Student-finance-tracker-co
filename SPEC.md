# Student Finance Tracker — Project Specification

## Purpose
Help students record expenses, monitor budgets,
search transactions, and manage spending.

## Main Sections
1. Dashboard
2. Transactions
3. Add/Edit Transaction
4. Settings
5. About

## Data Model
Each transaction contains:
- id
- description
- amount
- category
- date
- createdAt
- updatedAt

## Accessibility Plan
- Semantic HTML elements
- Keyboard navigation
- Visible focus indicators
- Skip-to-content link
- Accessible form labels
- ARIA live status messages
- Adequate color contrast

## Responsive Design
- Mobile: 360px
- Tablet: 768px
- Desktop: 1024px
